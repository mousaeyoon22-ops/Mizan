# قائمة الجاهزية للنشر العالمي في المتاجر الرقمية والامتثال القانوني

> **تنبيه إلزامي (حدود التفويض — البند 6):** البنود القانونية والمالية والنشر للعامة تتطلب قراراً وتفويضاً مباشراً من مالك المشروع.

## 1. المتطلبات القانونية والمؤسسية (قرار المالك)
- [ ] تأسيس كيان تجاري رسمي واستصدار رقم **D-U-N-S** (مطلوب لحسابات Apple وGoogle للمؤسسات المالية/التجارية).
- [ ] فتح حساب مطوّر مؤسسي في **Apple Developer Program** ($99/سنة) و**Google Play Console** ($25 مرة واحدة).
- [ ] إعداد ونشر صفحات **سياسة الخصوصية** و**شروط الاستخدام** و**آلية حذف الحساب والبيانات** على نطاق رسمي HTTPS.
- [ ] في المرحلة 2 فقط: توقيع عقد بوابة الدفع المرخصة (`Authorize & Capture`) وتفعيل `PSP_PASS_THROUGH_PREAUTH` و`KYC_STRICT_TIERS_2_TO_4`.

## 2. الامتثال التقني لسياسات المتاجر (تم تجهيزه برمجياً في v1.4)
- [x] **البند 2.1 من Apple (اكتمال التطبيق):** جميع ميزات المرحلتين 2 و3 مخفية تلقائياً من الشاشات الرئيسية ومحمية بـ `[RequireFeature]` لمنع أي أزرار ميتة.
- [x] **الإعفاء من عمولة 30%:** الدفع التمريري مخصص للسلع والخدمات المادية خارج التطبيق؛ مع تجهيز حساب تجريبي (Demo Account) لفريق المراجعة.
- [x] **أمان البيانات المحلية والنقل:** تشفير SQLCipher محلياً + TLS 1.3 + JWT Bearer + عزل RLS.

## 3. متطلبات الإطلاق التشغيلي قبل الرفع للمتاجر
- [ ] تشغيل CI/CD (`.github/workflows/ci.yml`) ونجاح `dotnet test` و`flutter test` و`k6_peak_storm.js` و`pgbench`.
- [ ] تنفيذ اختبار اختراق خارجي مستقل (OWASP API Top 10) ومراجعة مكتب محاسبة قانوني لقيود IFRS 15 / IAS 2 / IAS 21.
- [ ] توقيع حزم الإنتاج (Android App Bundle `.aab` وiOS Archive `.ipa`) بمفاتيح Keystore محفوظة بأمان.
