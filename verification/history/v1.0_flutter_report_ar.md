# تقرير بناء وتحقق نواة تطبيق Flutter — مشروع ميزان (Mizan Flutter v1.0)

## 1. نطاق الحزمة المكمّلة
تتكامل هذه الحزمة (`Mizan_Flutter_Client_v1.0`) مباشرة مع الخادم المبني سابقاً (`Mizan_Enterprise_NET8_v1.0`) عبر عقود REST OpenAPI 3.1 ومركز SignalR اللحظي، وتغطي العمل دون إنترنت (Offline-First)، والسلة الحية عبر QR، والدفع بالتفويض المسبق، ومنع تزوير اعتراضات التلف بالكاميرا الحية، والأبواب التجارية، والبحث القريب.

## 2. الحقائق المثبتة والاختبارات المنفّذة فعلياً الآن
* نُفّذ سكربت التحقق المستقل `verification/run_flutter_offline_verification.py` مباشرة فوق ملف المخطط الفعلي `assets/sql/001_mizan_offline_client.sql`.
* **النتيجة الفعلية:** نجاح **7 من أصل 7** اختباراً بنسبة فشل **0**:
  * دقة الحسابات المالية بالوحدات الصحيحة `MoneyMinor (x10000)` متطابقة تماماً مع `NUMERIC(18,4)` دون أخطاء الفاصلة العائمة.
  * منع الأسعار السالبة، ومنع تكرار مفاتيح `idempotency_key` في طابور المزامنة `sync_outbox` على مستوى قاعدة البيانات المحلية.
  * حفظ حالات التعارض (`CONFLICT`) دون فقدان صامت عند فشل المزامنة (HTTP 409).
  * تفعيل قفل الدردشة التوافقية كأرشيف قانوني للقراءة فقط عبر مشغّل SQLite (`trg_block_locked_chat_insert`).
  * حظر رفع صور الاستوديو وتقييد نافذة الاعتراض بـ 30 دقيقة للسلع القابلة للتلف.

## 3. البنود التي تتطلب تشغيلها محلياً (خارج هذه البيئة)
* تشغيل `flutter pub get` و`flutter test` لترجمة أكواد Dart وتشغيل اختبارات الوحدة المرفقة (`test/`).
* بناء الحزمة الموقّعة للأندرويد عبر `flutter build apk --release` واختبار أذونات الكاميرا والـ GPS والماسح الضوئي (QR) على جهاز هاتف حقيقي قبل إطلاق الاختبار الميداني للأشهر الأربعة.
